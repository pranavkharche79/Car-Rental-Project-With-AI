# 🚗 Car Rental Project (AI-Built)

## 📌 About

This is a **Car Rental Web Application** built to manage car listings, bookings, and rentals in a simple and user-friendly way.

> ⚠️ **Note:** This project was **created entirely using Artificial Intelligence (AI)**. AI was used for planning, coding, UI suggestions, problem-solving, and documentation.

---

## 🛠️ Tech Stack

* React.js
* TailwindCSS

---

## ✨ Features

* View available cars
* Book rental cars
* Manage car listings
* Simple and responsive UI

---

## 🚀 Run Locally

```bash
npm install
npm start
```
